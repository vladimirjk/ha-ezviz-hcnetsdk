# EZVIZ HCNetSDK Bridge

Local PTZ, alarm-event, and state bridge for compatible EZVIZ cameras exposing the
Hikvision HCNetSDK service on TCP port 8000. Extended PTZ APIs are firmware-dependent;
the default H6c setup exposes only its verified cardinal motor controls. Failed direct
sleep/wake and web-service experiments are not exposed.

See [DOCS.md](DOCS.md) for setup and API examples.
